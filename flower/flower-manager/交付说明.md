## 三、怎么演示

1. 打开在线地址。
2. 点击右上角金色 **AI** 按钮，打开“花掌柜 AI”。
3. 直接问：
   - 今天该补什么花？
   - 本周利润怎么样？
   - 自由精神玫瑰怎么定价？
   - 近 30 天什么花最好卖？
4. 回答下方会出现工具标签，例如“补货建议”“销售利润”，表示模型已经调用真实经营数据工具。
5. 页面任何库存、开单、调价操作都会自动保存到服务端，右上角显示“云端已保存”。

### 多人协作演示

1. 用两个浏览器（或电脑 + 手机）打开同一个在线地址。
2. 右上角头像会显示在线人数；点击头像可以设置称呼、查看成员、复制邀请链接。
3. 在 A 页面补货或开单，B 页面会自动更新，并弹出“小林 调整了库存，已实时同步”。
4. 两个人同时改同一枝花时，后提交的一方会看到冲突提示，页面自动刷新到最新数据，不会静默覆盖。
5. 如果正在开单或编辑弹窗，会先显示“同事刚刚更新了数据 · 点击同步”，不会打断当前输入。

### 顾客选花付款演示

1. 打开 `/shop`（或扫顾客选花二维码）。
2. 选花加入购物袋，点“去结算”。
3. 填写收花人、电话；选择到店自提或同城配送；选择日期时段和支付方式。
4. 点“去支付”进入演示支付页，确认支付。
5. 支付成功后页面给出订单号；花间集后台销售记录会出现带「线上」标签的新订单，库存同步扣减。
6. 打开后台订单详情，可以看到联系电话、配送地址、预约时间、支付方式和“已支付”。

> 当前是演示支付，不产生真实扣款；正式上线需要接入微信/支付宝商户号、支付回调和退款接口。

## 五、本地运行

要求 Node.js 22+。

```powershell
cd flower-manager
npm start
# 或
.\server\start.ps1
```

打开 http://localhost:8787

可选：复制 `.env.example` 为 `.env`，配置自己的模型 Key。

```powershell
Copy-Item .env.example .env
# 编辑 .env 中的 LLM_ENDPOINT / LLM_MODEL / LLM_API_KEY
npm start
```

## 六、模型说明

默认：

- Provider：Pollinations 匿名接口
- Model：`openai-fast`（GPT-OSS 20B）
- 支持 OpenAI 兼容的 tools 调用
- 免费额度约为每 45 秒 1 次；超过后自动切换为本地经营规则回答
- 本地规则同样会读取真实库存、销售、补货、定价数据，不是假数据

生产环境建议使用自己的模型：

```env
LLM_ENDPOINT=https://api.deepseek.com/chat/completions
LLM_MODEL=deepseek-chat
LLM_API_KEY=sk-...
```

服务端会隐藏 API Key，不会下发到浏览器。

## 八、上线与边界

- 当前是**共享单店协作版**：所有打开链接的人进入同一家店，默认拥有相同操作权限。
- 顾客端支付是**演示支付**，不会真实扣款；正式上线需接入微信/支付宝商户号、支付回调验签、退款接口与订单风控。
- 顾客端只暴露公开商品字段，服务端重新计算价格并校验库存，不信任浏览器提交的金额。
- 实时通道支持降级：本机/直连用 SSE；Cloudflare Quick Tunnel 缓冲 SSE 时自动切换为 2.5 秒轮询
- 当前公网环境已实测轮询同步：其他客户端修改后 2.5～4 秒内自动更新，并提示操作人和操作内容
- 尚未实现账号登录、角色权限、多门店租户隔离；正式商用前需要补上认证、数据库、审计日志和更严格的限流。
- Cloudflare Quick Tunnel 是临时地址，本机或服务端关闭后会失效。
- 若用 Render 免费计划部署，`server/data/state.json` 可能在实例重启后重置；正式使用需挂载持久磁盘或接入数据库。
- 本轮未使用 Docker 实际构建验证；Dockerfile 与 Render 配置按无第三方依赖的 Node 服务提供，本地 Node 启动已实测。
