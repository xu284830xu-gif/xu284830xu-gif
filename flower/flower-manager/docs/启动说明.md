# 花间集 · 启动与运行说明

> 适用版本：`1.2.0`　｜　最后核对：2026-11-13（命令均在本机实测）
> 所有命令都在项目根目录 `flower-manager/` 下执行

---

## 0. 先看这一张表（本机实测结果）

| 命令 | 本机状态 | 说明 |
| --- | --- | --- |
| `node server/server.mjs` | ✅ 可用 | **推荐**，不依赖 npm，也不需要改执行策略 |
| `node --env-file-if-exists=.env server/server.mjs` | ✅ 可用 | 需要读 `.env` 时用这个（Node ≥ 22） |
| `npm start` | ❌ 不可用 | 本机 PATH 里没有 npm（`node` 是某个工具自带的） |
| `.\server\start.ps1` | ❌ 被拦 | PowerShell 执行策略是 `Restricted`，见第 3 节绕过办法 |
| `.\server\start.ps1`（Bypass 方式） | ✅ 可用 | `powershell -ExecutionPolicy Bypass -File .\server\start.ps1` |

环境检查：

```powershell
node -v          # v24.16.0
npm -v           # 本机：找不到命令
Get-ExecutionPolicy   # 本机：Restricted
```

## 1. 启动全栈版（后台 + 顾客端 + AI）

```powershell
cd E:\花卉\flower-manager
node server/server.mjs
```

看到这几行就是成功：

```text
花间集服务已启动: http://localhost:8787
监听: 0.0.0.0:8787
状态数据: ...\server\data\state.json
AI: {"provider":"pollinations","model":"openai-fast",...}
```

浏览器打开 **http://localhost:8787**。

### 需要读 `.env` 时

```powershell
node --env-file-if-exists=.env server/server.mjs
```

`--env-file-if-exists` 是 Node ≥ 22.9 的参数；文件不存在也不会报错。

### 如果机器上装了 npm

```powershell
npm start        # 等价于 node --env-file-if-exists=.env server/server.mjs
```

`package.json` 里定义的脚本：

| 脚本 | 实际命令 |
| --- | --- |
| `npm start` | `node --env-file-if-exists=.env server/server.mjs` |
| `npm run seed` | `node server/scripts/make-seed.mjs` |
| `npm run test:api` | `node server/scripts/test-api.mjs` |
| `npm run test:collab` | `node server/scripts/test-collab.mjs` |
| `npm run test:storefront` | `node server/scripts/test-storefront.mjs` |

没有 npm 时，直接 `node server/scripts/test-api.mjs` 一样能跑。

## 3. Windows 脚本被拦（执行策略 Restricted）

直接 `.\server\start.ps1` 会报：

```text
无法加载文件 ...\start.ps1，因为在此系统上禁止运行脚本。
```

三种解法，任选其一：

```powershell
# ① 只对这一次生效（推荐，不改系统设置）
powershell -ExecutionPolicy Bypass -File .\server\start.ps1

# ② 只对当前用户放开（一次设置，长期有效）
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

# ③ 干脆不用脚本
node server/server.mjs
```

脚本本身只做三件事：设 `PORT=8787`、`HOST=0.0.0.0`，然后执行 `node --env-file-if-exists=.env server/server.mjs`。

## 4. 改端口 / 改监听地址

```powershell
# 临时改端口
$env:PORT = 9000
node server/server.mjs

# 只允许本机访问
$env:HOST = '127.0.0.1'
node server/server.mjs

# 一行版
$env:PORT=9000; node server/server.mjs
```

## 5. 配置 AI 模型（可选）

默认走 Pollinations 匿名接口，**不配也能用**（免费额度约 45 秒 1 次，超出自动切本地规则）。

```powershell
Copy-Item .env.example .env
# 编辑 .env，填写：
#   LLM_ENDPOINT=https://api.deepseek.com/chat/completions
#   LLM_MODEL=deepseek-chat
#   LLM_API_KEY=sk-xxxxxxxx
node --env-file-if-exists=.env server/server.mjs
```

| 变量 | 作用 | 默认 |
| --- | --- | --- |
| `PORT` / `HOST` | 监听端口与地址 | `8787` / `0.0.0.0` |
| `LLM_ENDPOINT` / `LLM_MODEL` / `LLM_API_KEY` | 模型服务 | Pollinations `openai-fast` |
| `LLM_DISABLE=1` | 强制只用本地经营规则 | 关 |
| `LLM_TIMEOUT_MS` | 模型超时 | `60000` |
| `SHOP_HOURS` / `SHOP_PHONE` / `SHOP_DELIVERY_NOTE` / `SHOP_PICKUP_NOTE` | 顾客端展示信息 | 内置文案 |

## 6. 临时公网地址（HTTPS 演示）

```powershell
powershell -ExecutionPolicy Bypass -File .\server\start-public.ps1
```

流程：启动本地 node 服务 → 调用 `server/bin/cloudflared.exe` 建 Quick Tunnel（首次自动下载）→ 打印 `https://xxxx.trycloudflare.com`。

注意：

- 地址**每次启动都不同**，进程关掉立即失效；
- 需要能连上 Cloudflare 出网；
- 只适合现场演示，别印在交付材料上当固定地址。

## 8. 自检脚本

三个脚本默认请求 `http://127.0.0.1:8787`，**先启动服务**再跑：

```powershell
node server/scripts/test-api.mjs          # 健康检查、只读接口、参数校验
node server/scripts/test-collab.mjs       # 双客户端并发同步、冲突 409
node server/scripts/test-storefront.mjs   # 顾客下单、扣库存、幂等、恢复
```

- 结束时会用差量同步把数据**恢复**回去，但 `meta.revision` 会变化；
- 跑之前建议备份 `server/data/state.json`；
- `test-api` 支持环境变量 `BASE_URL` 覆盖目标地址。

## 9. 部署

**Docker**

```bash
docker build -t huajian-flower .
docker run -p 8787:8787 -e PORT=8787 huajian-flower
```

**Render**：仓库里有 `render.yaml`，连仓库建 Web Service 即可。免费实例重启会重置 `server/data/state.json`，正式使用要挂持久磁盘或换数据库。

**自己的服务器**：`node server/server.mjs` 常驻（systemd / pm2），Nginx/Caddy 反代做 HTTPS；SSE 需要关闭代理缓冲，服务端已带 `X-Accel-Buffering: no`。

## 10. 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `npm : 无法将“npm”项识别为...` | 本机没装 npm | 用 `node server/server.mjs`，或安装 Node 官方版 |
| `因为在此系统上禁止运行脚本` | 执行策略 Restricted | 见第 3 节的 Bypass 写法 |
| `bad option: --env-file-if-exists` | Node < 22.9 | 升级 Node，或去掉该参数 |
| `EADDRINUSE` | 8787 被占 | `$env:PORT=9000; node server/server.mjs` |
| 页面 404 / 白屏 | 不在项目根目录启动，找不到 `index.html` | `cd` 到 `flower-manager` 再启动 |
| 数据为空或是旧数据 | 数据在 `server/data/state.json` | 删掉该文件会按 `seed.json` 重新初始化 |
| 改了页面不生效 | 静态资源有缓存 | `Ctrl + F5` |
| AI 总是「本地规则」回答 | 匿名接口限流或没网 | 配 `LLM_API_KEY`，或接受本地规则 |
| 公网地址打不开 | Quick Tunnel 已退出 | 重新执行 `start-public.ps1`，地址会变 |
